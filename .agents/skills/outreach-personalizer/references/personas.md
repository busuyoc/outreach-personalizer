# Reference: why Plausible Analytics as the demo target

Real, small-to-mid, self-serve B2B SaaS with plenty of public copy — and,
usefully, a company with a specific stated worldview (privacy-first,
EU-hosted, deliberately lightweight, anti-tracking-bloat). That gives a
buyer-role persona something sharper to react to than generic filler: a lazy
personalization pass that uses PII-flavored "tracking" language on a company
that sells *not* doing that is a genuine, checkable failure mode, not a
matter of writing style.

## Head of Growth at Plausible Analytics — grounded reaction pattern

**Resonates with:** privacy-first framing, EU-hosting/data-residency angles,
concrete numbers over hype (their own copy is dry and precise, not salesy).

**Objects to:** any pitch implying visitor-level tracking, profiling, or
fingerprinting — contradicts the product's whole premise; generic
"AI-powered growth" language, which reads as exactly the hype they position
against; anything that reads as scraped/formulaic rather than genuinely
researched.

This is not a fixed script — step 4 of `SKILL.md` grounds the reaction in
whatever was actually fetched at run time, and `SKILL.md` deliberately never
instructs the agent to read this file during a run: the live reaction must
come from fetched evidence alone, on any company. This file documents why
this demo target was chosen and what the checkable failure mode looks like;
it is scoping context, not a substitute for the live fetch.
